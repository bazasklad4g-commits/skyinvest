# SkyInvest

Две браузерные концепции для сети лендингов зарубежной недвижимости.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте:

- `/` — экран сравнения;
- `/concept-a` — Private Selection;
- `/concept-b` — Investment Editorial.

Формы сейчас работают как интерактивный прототип и не отправляют данные.

Исследование находится в `docs/RESEARCH.md`, техническое задание — в `docs/TECHNICAL-SPEC.md`.
