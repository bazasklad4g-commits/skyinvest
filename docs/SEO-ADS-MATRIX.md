## Для Google Ads

Для каждой посадочной страницы в `content/landing-pages.ts` лежат связанные с ней заголовки и описания объявления. Их стоит расширить до RSA после запуска, когда появится отчёт по фактическим поисковым терминам. Правило сейчас простое: заголовок объявления повторяет страну и тип подбора на первом экране, а описание ведёт к понятной форме «подборка в мессенджер», а не к несуществующему прайсу.

События для GTM заведены без передачи номера телефона:

- `lead_form_phone_submit`
- `lead_form_complete`
