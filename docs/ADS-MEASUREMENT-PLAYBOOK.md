# Настройки кампаний и цикл улучшений

Срез: 3 августа 2026. Документ описывает только новые просветительские Search-кампании с префиксом `[PAUSED] EDU |`. Название кампаний сохранено как техническая метка, но 1 августа 2026 включены все 24 кампании, их 24 clean-группы и 24 RSA. После пересборки 3 августа в группах 234 ключа. Файл не меняет рекламу.

Текущий технический экспорт хранится в `docs/ADS-INVENTORY-2026-07-29.md`. Его можно обновить из корня проекта командой:

```bash
.venv/bin/python scripts/ads_inventory_report.py
```

## Общие настройки

| Параметр | Значение |
|---|---|
| Тип | Google Search |
| Статус кампаний, clean-групп, RSA и ключей | ENABLED с 01.08.2026 |
| Стратегия | Maximize Conversions |
| Сети | Google Search включён; Search Partners и Display выключены |
| Группа | Одна тематическая группа на кампанию: `[CLEAN] EDU | …` |
| Объявление | Одна RSA на группу; обещает конкретный бесплатный материал |
| Ключи | Только phrase и exact, от 3 до 8 смысловых фраз на кампанию |
| Минус-слова | `купить`, `продажа`, `цена`, `стоимость`, `прайс`, `каталог`, `объекты`, `риелтор`, `рассрочка`, `работа`, `вакансии`, `резюме`, `стажировка`, `туры`, `отель`, `погода`, `карта`, `скачать фильм`, `паспорт` |
| Основная конверсия | Отправка формы. До старта нужно проверить, что один лид не создаёт два primary-события. |
| Вторичные сигналы | Клик в Telegram, звонок и локальные действия; они не должны участвовать в ставках. |

## Контроль запуска и первые проверки

1. Страница отдаёт HTTP 200, заголовок и текст RSA говорят об одном материале.
2. Материал можно получить как образовательный результат, а не только как предлог для коммерческого подбора.
3. В URL, title, description и тексте страницы нет ложных цифр, обещаний результата или цены.
4. В Google Ads добавлены хотя бы два релевантных sitelink; расширения ведут на существующие разделы.
5. В DebugView GA4 видно `form_start` и один `lead_submit`; заявка доходит в Google Sheets и Telegram с URL страницы, типом формы и выбранными странами.
6. Для Google Ad Grants площадка должна правдиво отражать миссию НКО. Этот пункт нельзя временно поставить «для модерации» и затем убрать.

## Цикл «КАРПАТИ»

Это внутренний порядок работы, не термин Google. Его запускаем раз в неделю по всем включённым кампаниям; первые две недели после старта смотрим поисковые запросы каждые 2–3 дня.

| Буква | Действие | Что фиксируем |
|---|---|---|
| К | Ключевые слова и поисковые запросы | Что добавили, что вынесли в минус, причины решения |
| А | Объявления | CTR, соответствие заголовка материалу, RSA с низкой вовлечённостью |
| Р | Релевантность страницы | Связка запрос → объявление → главный экран → форма |
| П | Путь пользователя | Переходы, `form_start`, `lead_submit`, доля квалифицированных заявок |
| А | Аналитика | UTM, GCLID, источник в Sheets, отсутствие дубля конверсии |
| Т | Тест | Одна понятная правка за раз: текст, оффер или блок страницы |
| И | Итог | Результат теста, решение оставить/откатить, дата следующей проверки |

## Таблица для еженедельного замера

Создайте одну строку на кампанию за период. Метрика `Квалифицированные лиды` берётся из Google Sheets после ручной проверки, а не из клика по кнопке.

| Период | Кампания | Показы | Клики | CTR | Расход | Ср. CPC | `form_start` | `lead_submit` | Квалифицированные лиды | CVR лидов | Цена квалиф. лида | QS 1–2 | Решение по запросам | Что тестируем | Ответственный | Следующая проверка |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |

Формулы: `CTR = клики / показы`; `CVR лидов = lead_submit / клики`; `цена квалифицированного лида = расход / квалифицированные лиды`. Если ключ получил Quality Score 1–2, его ставим на паузу; если запрос не ведёт к теме бесплатного материала, добавляем минус-слово.

## Граница ответственности

Google Ads показывает клики и первичные конверсии. Google Sheets и Telegram дают контекст лида. Решение, считать ли лид качественным, принимает человек после проверки запроса; без этого алгоритм начнёт оптимизироваться под пустые номера и случайные отправки формы.
